## --Быстрый старт--

### Требования
- Python 3.8+
- PostgreSQL 10+
- Git

### Установка за 5 минут

```bash
# 1. Клонировать репозиторий
git clone https://github.com/soulbratan/Attestation_task
cd electronics-network

# 2. Создать виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows

# 3. Установить зависимости
poetry update

# 4. Настроить переменные окружения
cp .env.example .env
# Отредактировать .env файл

# 5. Применить миграции
python manage.py migrate

# 6. Создать тестовые данные
python manage.py createtestdata

# 7. Создать суперпользователя
python manage.py createsuperuser

# 8. Запустить сервер
python manage.py runserver
```
Перейдите по адресу:

Приложение: http://localhost:8000

Документация API: http://localhost:8000/swagger/

Админ-панель: http://localhost:8000/admin/

## --Архитектура--

### Иерархия сети
Завод (уровень 0) → Розничная сеть (уровень 1) → ИП (уровень 2+)

### Каждый элемент имеет:
- Название и контактные данные
- Ссылку на поставщика
- Список продуктов
- Задолженность перед поставщиком
- Время создания и уровень

### Технологический стек
Backend: Django 4.0 + Django REST Framework

База данных: PostgreSQL

Аутентификация: JWT (Simple JWT)

Документация: Swagger/OpenAPI (drf-yasg)

Фильтрация: Django Filter

Переменные окружения: python-dotenv


##  --Установка и настройка--
1. Настройка базы данных PostgreSQL
```bash
CREATE DATABASE electronics_network;
CREATE USER electronics_user WITH PASSWORD 'your_password';
```
2. Настройка переменных окружения (.env) по аналогии с .env.sample.
3. Выполнить миграции
```bash
python manage.py makemigrations
python manage.py migrate
```
4. Создать суперпользователя и тестовые данные.
```bash
python manage.py createsuperuser
# или используйте тестовые данные
python manage.py createtestdata
```

## --Аутентификация и безопасность--

***Ролевая модель***
- Суперпользователи: Полный доступ ко всему
- Менеджеры: Доступ к админке и API
- Сотрудники: Доступ только к API (только активные)
- Зарегистрированные: Ожидание активации
- Анонимы: Только регистрация и вход

***Меры безопасности***
- JWT токены с expiration
- HTTPS рекомендован для продакшена
- Валидация входных данных на всех уровнях
- Защита от SQL-инъекций (ORM Django)
